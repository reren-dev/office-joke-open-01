One line of office comedy, written for the [make.fun](https://make.fun) bounty
"Make the AI Judge Laugh: the Office Joke Open".

`main.py` writes a single joke — at most 200 characters — to
`/output/entry.txt`:

> I hit reply-all to ask everyone to stop hitting reply-all, and now HR wants a meeting about my tone.

Run it with `python3 main.py`. The output is deterministic: every run
writes the exact same line.
